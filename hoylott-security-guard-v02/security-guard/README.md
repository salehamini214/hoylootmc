# HOYLOTT Security Guard v0.2
## نصب در مخزن موجود
فقط پوشه `security-guard` را در ریشه مخزن `hoylootmc` آپلود و Commit کنید؛ فایل‌های اصلی سایت را جایگزین نکنید.
آدرس مورد انتظار: `https://salehamini214.github.io/hoylootmc/security-guard/`

## قابلیت‌ها
- راهنمای اضطراری USSD گزارش‌شده برای خروج دستگاه‌های فعال روبیکا
- چک‌لیست اقدامات پس از خروج نشست‌ها
- بررسی ابتدایی متن و لینک‌های مشکوک
- ثبت گزارش فقط در localStorage مرورگر
- PWA و کش آفلاین

## محدودیت و ایمنی
این سایت USSD را اجرا نمی‌کند، به روبیکا وصل نیست و نشست‌ها را از راه دور قطع نمی‌کند. شماره منو ممکن است تغییر کند؛ متن منوی اپراتور را ملاک قرار دهید. عملیات ممکن است همه دستگاه‌های دیگر را خارج کند. هیچ رمز، کد ورود، کوکی یا توکنی در این سایت وارد نکنید.
