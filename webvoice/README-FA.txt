HOYLOTT WebVoice - نسخه اولیه

قابلیت‌ها:
- ساخت گروه صوتی و دریافت کد دعوت
- ورود به گروه با کد
- میکروفون روشن/خاموش
- نمایش اعضای گروه
- بدون نصب مود یا پلاگین روی کلاینت Minecraft
- سقف گروه در این نسخه: 8 نفر

نیازمندی:
- Node.js نسخه 18 یا بالاتر
- دسترسی اینترنت برای نصب بسته‌ها
- برای دسترسی بیرون از کامپیوتر خودت، سایت باید HTTPS داشته باشد
- این نسخه از WebRTC با سرور STUN عمومی استفاده می‌کند؛ بعضی شبکه‌ها به TURN server نیاز دارند.

اجرا در ویندوز:
1. Node.js نصب کن: https://nodejs.org/
2. ZIP را استخراج کن.
3. داخل پوشه HOYLOTT-WebVoice در نوار آدرس File Explorer بنویس cmd و Enter بزن.
4. اجرا کن:
   npm install
5. سپس:
   npm start
6. در همان کامپیوتر باز کن:
   http://localhost:3000

برای تست از گوشی/کامپیوتر دیگر:
- localhost فقط برای همان دستگاه است.
- برای استفاده از اینترنت باید روی سرور/هاست قرار بگیرد و HTTPS فعال باشد.
- پورت پیش‌فرض برنامه 3000 است؛ برای دسترسی عمومی باید شبکه و فایروال هم تنظیم شوند.

نکته مهم امنیتی:
این نسخه یک نمونه اولیه است، نه سرویس آماده عمومی. کد گروه تصادفی است اما احراز هویت Minecraft، رمز گروه، محدودیت ضداسپم و TURN اختصاصی هنوز ندارد. هرگز آن را بدون HTTPS و کنترل دسترسی روی اینترنت عمومی رها نکن.
